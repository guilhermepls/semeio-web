# Semeio Hábitos - Sistema Web de Monitoramento de Hábitos

Com o Semeio Hábitos, você escolhe um hábito de foco por mês, marca os hábitos de cada dia, registra um momento memorável e o humor, e acompanha tudo em calendário e gráfico.

> **Privacidade:** Os dados ficam registrados apenas no seu navegador (`Local Storage`).
## Como rodar
```bash
npm install
npm run dev
```
